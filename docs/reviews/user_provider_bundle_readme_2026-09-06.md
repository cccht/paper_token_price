# User--manufacturer game reproduction bundle

Open `llm_user_provider_game_2026-09-06.pdf` (13 pages). The primary fixed-price before/after result is on page 7; the equally strategic uniform/TOU comparison is on page 9. The latter is adverse for users in all five predefined cohorts.

Detailed results and exact commands are in `artifacts/user_provider_game/20260906/README.md`. Paths retain the project layout, so commands run at this archive's root. This bundle includes the actual processed workload input, quality-calibration inputs, complete new-model results, solver dependencies, tests, figure scripts and licensed icons, vector/raster exports, manuscript sources, bibliography, and audit records. It reproduces the new normalized-task experiment; it is not a copy of the complete upstream BurstGPT trace or of unrelated historical experiments.

`bundle_manifest.json` binds every included member to a SHA-256 and its source path. `verification.json` inside the results directory is the 50,625-pair finite-game replay certificate. There is no claim of continuous-price optimality, empirical user validation, or universal welfare improvement. No historical source files were deleted or moved to make this bundle.
